SOUND TUI CD Player

F# で実装した Windows 向けターミナル CD プレイヤー。光学ドライブの CD-DA 再生、10 バンド EQ、スペクトル表示、WAV 抽出を一つの対話型 TUI にまとめる。

版 1.0 日付 2026-09-12 言語 F# / .NET 10 OS Windows リポジトリ TUI_SoudCDPlayer

01概要

本ソフトウェアは、コンソール上でコンパクトディスクのように扱える再生機である。実ディスク、フォルダ内の音声ファイル、内蔵デモ信号を同じ「ディスク / トラック」モデルで扱い、デジタル経路では再生中にグラフィックイコライザを適用する。

できること

  • CD-DA のデジタル再生（EQ 付き）
  • MCI フォールバック再生
  • フォルダをアルバムとして開く
  • デモ信号で EQ を試聴
  • 選択 / 全トラックの WAV 抽出
  • ライブ・スペクトルと 10 バンド EQ

やらないこと

  • CD-TEXT / MusicBrainz による自動タグ付け
  • データ CD / DVD / Blu-ray の再生
  • エンコード済み形式（MP3 等）へのリッピング
  • クロスプラットフォームの光学ドライブ制御
  • GUI（WinForms / WPF / Web）

02目的と範囲

目的

  1. 端末だけで CD の選曲・再生・停止・シークができること
  2. デジタル PCM 経路で 10 バンド EQ が即座に音へ乗ること
  3. ディスクが無い環境でもデモディスクで操作と EQ を確認できること
  4. CD-DA を可逆に近い形（44.1 kHz / 16 bit / stereo WAV）で取り出せること

品質方針

  • 再生と抽出は同じ TOC / LBA 情報を共有する
  • 光学ドライブが生読み取りできない場合は再生を止めず MCI に落とす
  • 抽出中はドライブ競合を避けるため再生を停止する
  • ファイル名やパスに含まれる Spectre マークアップ文字はエスケープする

06ドメイン

ディスクとトラック

すべての音源は Disc と Track[] に正規化する。トラックは再生用 TrackSource と、抽出用の任意 RipInfo を持つ。

TrackSource意味
DigitalCdデバイスハンドル + 開始 LBA + セクタ数。EQ 可能な PCM 経路
MciCdドライブレター + トラック番号。Windows MCI で再生
AudioFileファイルパス。AudioFileReader
DemoTone生成信号の種類
DiscKind表示EQ抽出
DigitalAudioCdCD DIGITALありあり
MciAudioCdCD MCIなし（再生）TOC が取れれば試行
FolderDiscFOLDERありなし
DemoDiscDEMOありなし

時間

CD の 1 秒は 75 セクタ。LBA は (M×60+S)×75+F−150。トラック長は次トラック開始（またはリードアウト）との差分。

07再生パイプライン

デジタル経路は次のサンプルチェインで WaveOutEvent に渡す。

→

→

→

→

  • 位置とシークは元の WaveStream が担う
  • EQ 変更は再生中でも EqualizerProvider.Update で係数だけ差し替える
  • 自然終了は PlaybackStopped。リピート One / All / Off とシャッフルで次トラックを決める
  • MCI 経路はこのチェインを使わず、play / pause / resume / stop と位置ポーリングだけ行う

08CD 読み取り

検出順

  1. DriveInfo から CDRom を列挙する
  2. \\.\X: を GENERIC_READ + 共有 Read/Write で開く
  3. IOCTL_CDROM_READ_TOC で TOC を読む
  4. Control ビット 0x04 のデータトラックは捨て、オーディオだけ残す
  5. 先頭 1 セクタを IOCTL_CDROM_RAW_READ（CDDA, 2352 byte）で試し読みする
  6. 成功なら Digital。失敗ならハンドルを閉じ、MCI で再生しつつ TOC から RipInfo を後付けする

生読み取りの約束

  • 出力はセクタあたり 2352 バイト（16 bit / 2 ch / 588 フレーム = 1/75 秒）
  • RAW_READ_INFO.DiskOffset は LBA × 2048（cooked サイズ）。2352 ではない
  • 一度に読むセクタ数は 26 以下（多くの ATAPI の上限に合わせる）
  • 再生用 CdWaveStream は要求バイト数に合わせてセクタ境界からコピーする

09イコライザ

中心周波数 32 / 64 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz。Q = 1.41（約 1 オクターブ）。ゲインは −12〜+12 dB。

  • フィルタはバンド × チャンネルで持ち、状態を混ぜない
  • ナイキスト近傍以上のバンドは作らない
  • 処理後は ±1.0 にクランプする
  • T でバイパス。F / 0 で全バンド 0 dB

10スペクトル

  • FFT サイズ 2048（2 の冪）。Hann 窓
  • ステレオは加算平均してモノ化する
  • 表示は約 40 Hz〜16 kHz を対数間隔のバーへ畳む
  • レベルはおおよそ −72 dB を床にした正規化
  • バーは即時上昇、緩やか減衰。ピークは別減衰
  • 停止中は Decay だけ進める

11抽出

抽出は再生とは別タスクで走る。開始時に再生を止め、同じ TOC の LBA 範囲を WAV に書く。

項目仕様
形式WAV、44 100 Hz、16 bit、ステレオ（CD-DA そのまま）
ファイル名01 トラック 01.wav。禁則文字は _
既定フォルダ%USERPROFILE%\Music\SOUND\<ディスク名>
再試行チャンク 3 回。失敗時は 1 セクタずつ
キャンセルフラグを見て未完了ファイルを削除
進捗曲番号、曲名、バイト比。TUI の EXTRACT パネルへ反映

デモ / フォルダディスクは Rip が無いので拒否する。MCI ディスクは TOC 再取得で LBA が埋まれば抽出できる。

12TUI と操作

Spectre.Console の Live を約 20 FPS で更新する。フォルダ選択と抽出先指定だけ Live を抜け、プロンプト後に戻る。

キーフォーカス動作
Space共通再生 / 一時停止
S共通 / 抽出中停止、または抽出キャンセル
Enterトラック選択曲を再生
N / P共通次 / 前（3 秒超なら曲頭）
← →トラック / EQ5 秒シーク / バンド移動
↑ ↓トラック / EQ選択移動 / ゲイン ±1 dB
Tab共通トラック ↔ イコライザ
X共通抽出プロンプト
D O M E共通CD 検出 / フォルダ / デモ / 取り出し
Q共通終了（抽出中なら先にキャンセル）

画面は TRANSPORT、任意の EXTRACT、SPECTRUM、EQUALIZER、TRACKS または HELP、フッタの順。フォーカス中のパネルはゴールド枠にする。

14状態遷移

再生

StoppedSpace / Enter で Playing
PlayingSpace で Paused。終端で次曲または Stopped
PausedSpace で Playing。S で Stopped

抽出

RipIdleX でプロンプト
RipRunning進捗更新。S / Esc でキャンセル
RipDone / Failed / Canceled結果をパネル表示

Live を抜ける理由

PendingAction が OpenFolder / RipPrompt / Quit のときだけループを抜ける。Quit 以外はプロンプト後に Live を再開する。

15制約と今後

現在の制約

  • Windows 専用のドライブ制御
  • MCI 再生では EQ とシークが効かない
  • CD-TEXT を読まないため曲名は「トラック NN」
  • 抽出は WAV のみ。エラー耐性は簡易リトライ止まり
  • 同一ハンドルでの再生と抽出は同時に行わない

拡張余地

  • CD-TEXT / MusicBrainz のタイトル付与
  • FLAC 出力とオフセット補正
  • プリセット EQ（bass / vocal / flat）
  • プレイリストとギャップレス
  • 複数ドライブ選択 UI
