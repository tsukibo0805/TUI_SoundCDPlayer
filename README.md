# SOUND — TUI CD Player

F# で書いたターミナル向け CD プレイヤーです。10 バンドのグラフィックイコライザとスペクトル表示が付きます。

## 必要環境

- Windows
- [.NET 10 SDK](https://dotnet.microsoft.com/)
- 光学ドライブ（CD 再生時）。無い場合はデモディスクか音声フォルダで使えます

## 起動

```powershell
dotnet run -- --demo
```

```powershell
dotnet run
```

ディスクが入っていれば CD を検出します。無ければデモディスクになります。

```powershell
dotnet run -- "C:\path\to\album"
```

フォルダ内の WAV / MP3 / M4A などをアルバムとして開きます。

## CD 抽出

CD-DA を 44.1kHz / 16bit / ステレオの WAV に書き出します。再生中に `X` を押すか、次のコマンドを使います。

```powershell
dotnet run -- --rip
dotnet run -- --rip --track 3
dotnet run -- --rip --out "C:\rips"
```

既定の出力先は `ミュージック\SOUND\<ディスク名>` です。抽出中は `S` または `Esc` でキャンセルできます。

## 主なキー

| キー | 動作 |
|------|------|
| Space | 再生 / 一時停止 |
| Tab | トラック一覧 ↔ イコライザ |
| ↑↓ / +/- | 選択、または EQ ゲイン |
| ←→ | 5 秒シーク（EQ フォーカス時はバンド移動） |
| , . | 音量 |
| X | CD を WAV 抽出 |
| D / O / M | CD 検出 / フォルダ / デモ |
| T / F | EQ バイパス / フラット |
| ? / Q | ヘルプ / 終了 |

## Discord で聞こえないとき

コマンドプロンプトのウィンドウは Discord から見ると別プロセスなので、そこだけ共有しても音は乗りません。

通常は TUI だけです。`W` を押すと **SOUND CD Player** 共有窓が開きます。TUI の映像をこのアプリ自身の窓に映しているので、Discord では **この窓** を共有してください。もう一度 `W` で閉じます。

画面全体共有＋「コンピューターの音声を共有」でも聞こえます。

## 再生経路

- CD-DA はまずデジタル読み取りし、PCM に EQ をかけて再生します
- 生読み取りができないドライブは MCI にフォールバックします（その場合 EQ は音に乗りません）
- デジタル読み取りには環境によって管理者権限が必要です
