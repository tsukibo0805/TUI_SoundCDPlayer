# 02. 値と関数

F# の基本単位は「名前を付けた値」です。関数も値です。

対応コード: `src/Domain.fs` の `TimeFmt` と `EqPreset.clampGain`

演習: `study/exercises/01-values.fsx`

## let は代入ではない

```fsharp
let volume = 0.85
```

これは「箱に入れる」ではなく、「`volume` という名前を 0.85 に付ける」です。あとから `volume <- 0.9` とは書けません。

変えたいときは、新しい名前（または同じ名前の新しいスコープ）を作ります。

```fsharp
let volume = 0.85
let louder = volume + 0.05
```

本番の `AudioPlayer` では可変フィールドも使いますが、計算そのものはこの不変スタイルです。まずはこちらに慣れます。

## 型推論

型を書かなくても、コンパイラが決めます。

```fsharp
let n = 3          // int
let x = 3.0        // float（64bit）
let g = 3.0f       // float32。本番の EQ ゲインはこちら
let s = "SOUND"    // string
let on = true      // bool
```

SOUND では次の intern がよく出ます。

| 書き方 | 型 | 用途 |
|--------|----|------|
| `12.f` / `0.85f` | `float32` | EQ、音量、スペクトル |
| `12.0` | `float` | 秒、比率 |
| `0n` | `nativeint` | Win32 ハンドル |
| `75` | `int` | LBA、トラック番号 |

明示したいときは注釈を付けます。

```fsharp
let clampGain (db: float32) =
    Math.Clamp(db, -12.f, 12.f)
```

これは `EqPreset.clampGain` そのものです。

## 関数の定義

```fsharp
let add a b = a + b
```

呼び出すときはカッコなしが基本です。

```fsharp
add 2 3
```

引数が式のときは、その式だけカッコで囲みます。

```fsharp
printfn "%d" (add 2 3)
```

1 つの引数だけの関数は、こうも書けます。

```fsharp
let double x = x * 2
```

関数の本体が複数行なら、インデントします。最後に評価された式が戻り値です。`return` キーワードはありません。

```fsharp
let mmss totalSeconds =
    let total = max 0.0 totalSeconds
    let m = int total / 60
    let s = int total % 60
    sprintf "%02d:%02d" m s
```

## パイプライン

`|>` は「左の値を、右の関数の最後の引数に渡す」演算子です。

```fsharp
let text =
    125.7
    |> int
    |> string
```

`Player.LoadFolder` では、ファイル列をこう繋いでいます。

```fsharp
Directory.EnumerateFiles(path, "*.*", SearchOption.AllDirectories)
|> Seq.filter (fun f -> audioExtensions.Contains(...))
|> Seq.sort
|> Seq.toArray
```

上から下へ「何をしたか」が読めます。ネストした関数呼び出しより、このアプリの流儀に近いです。

## 匿名関数

`fun` は名前のない関数です。`filter` や `map` の中に直書きします。

```fsharp
fun f -> Path.GetExtension(f).ToLowerInvariant()
```

C# の `f => ...`、Python の `lambda f: ...` に相当します。

## 文字列

通常の文字列は `"..."` です。補間は `$` を付けます。

```fsharp
let title = "デモディスク"
let n = 4
let msg = $"{n} 曲をロードしました"
```

書式を埋め込むときは、本番と同じ `%02d` が使えます。

```fsharp
$"%02d{m}:%02d{s}"
```

複数行は `"""..."""` です。`View.fs` の画面テキストや `Program.fs` のヘルプがこの形です。

## 演算と変換

F# は数値型を暗黙に混ぜません。`int` と `float` を足すときは変換します。

```fsharp
let seconds = float sectors / 75.0
```

`CdMath` と `TimeFmt.fromSectors` がまさにこれです。CD は 1 秒 = 75 セクタです。

```fsharp
module CdMath =
    let msfToLba (m: int) (s: int) (f: int) = (m * 60 + s) * 75 + f - 150
```

分・秒・フレーム（75 分の 1 秒）を、ディスク上の論理ブロックアドレスに変換しています。純関数なので、同じ入力ならいつも同じ整数が返ります。

## 無視する

戻り値が要らないときは `|> ignore` または `ignore (...)` です。

```fsharp
Directory.CreateDirectory dir |> ignore
```

`CreateDirectory` は作ったディレクトリ情報を返します。使わないと F# が警告します。

## 本番コードを読む

`src/Domain.fs` の `TimeFmt` を開いてください。

1. `mmss` は `TimeSpan` を受け取り、文字列を返す
2. 負の秒を `max 0.0` で落としている
3. 表示用の計算だけで、プレイヤーの状態は触らない

「入力 → 出力。途中の名前は `let`。最後の式が戻り値」が、F# の関数の基本形です。
