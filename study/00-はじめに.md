# 00. はじめに

SOUND は、ターミナルの中で動く CD プレイヤーです。F# で書かれています。

このレッスンでは、F# がどんな言語か、このアプリがどんな部品に分かれているかを先に見ます。文法は次の回からです。

## SOUND がやっていること

起動すると、次の循環がずっと回ります。

```
キー入力 → 状態を更新 → 画面を描き直す → またキーを待つ
```

状態の中身はざっくりこうです。

- 今どのディスクか（CD / フォルダ / デモ）
- 再生中か、止まっているか
- どのトラックを選んでいるか
- イコライザの各バンドのゲイン
- 抽出（リップ）中かどうか

画面は Spectre.Console、音は NAudio、CD の生読み取りは Windows API です。F# はそれらを繋ぐ「設計と状態」の言語として使われています。

## なぜ F# か

F# は .NET 上の関数型言語です。C# と同じライブラリを呼べますが、次の書き方が中心です。

| 考え方 | このアプリでの例 |
|--------|------------------|
| データを型で先に決める | `PlaybackState`, `TrackSource` |
| 値は原則として不変 | `TimeFmt.mmss` は入力を壊さない |
| 場合分けをコンパイラに検査させる | `match state with Playing -> ...` |
| 失敗は例外より型で表す | `Result`, `option` |

C# なら `enum` と `if` と `null` で書きがちなところが、F# では「あり得る場合」を型に列挙します。SOUND の中心はその型設計です。

## ファイルの役割

コンパイル順は `Sound.CdPlayer.fsproj` に書いてあります。F# は **上から順にしか見えません**。後のファイルは前のファイルを使えますが、逆はできません。

```
src/Domain.fs          状態・ディスク・EQ の型。依存なし
src/Equalizer.fs       10 バンドの音声フィルタ
src/Spectrum.fs        スペクトル表示用の解析
src/DemoSignal.fs      ドライブが無くても鳴るテスト音
src/CdDrive.fs         CD の検出・読み取り・MCI
src/Ripper.fs          CD → WAV
src/Player.fs          再生エンジン（可変状態の塊）
src/View.fs            TUI の描画
src/ShareWindow.fs     W キーのミラー窓
src/App.fs             キー入力とメインループ
Program.fs             起動、CLI、自己診断
```

最初に読むべきは `Domain.fs` です。型が分かると、他のファイルは「その型をどう使うか」になります。

## F# のプログラムの見た目

最小の例です。

```fsharp
let add a b = a + b

let answer = add 2 3

printfn "答えは %d" answer
```

- `let` で名前を付ける
- 関数の引数にカッコは不要（付けることもできる）
- 型を書かなくても、コンパイラが推論する
- 文末のセミコロンは不要

SOUND の中にも、同じ書き方がそのまま出てきます。

```fsharp
module TimeFmt =
    let mmss (t: TimeSpan) =
        let total = max 0.0 t.TotalSeconds
        let m = int total / 60
        let s = int total % 60
        $"%02d{m}:%02d{s}"
```

`01:05` のような表示を作る純関数です。入力の `TimeSpan` は変わりません。戻り値の文字列だけが新しい値です。

## 関数型でもクラスは使う

「F# = 全部が不変」ではありません。音声再生は「今どこまで読んだか」を抱え続けるので、`AudioPlayer` はクラスです。`let mutable` も使います。

使い分けの感覚はこうです。

- **型と計算**: 判別共用体・レコード・関数（`Domain.fs`）
- **動いている機械**: クラスと可変フィールド（`Player.fs`）
- **外部世界**: インターフェイス実装（NAudio, Windows）

初心者は、まず型と関数から入ります。クラスは 08 で扱います。
