# 01. 環境と最初のプログラム

ツールを確認し、F# を 1 行実行できる状態にします。

## SDK を確認する

PowerShell で次を実行します。

```powershell
dotnet --version
```

このアプリの対象は `net10.0-windows` です。SDK 10 系が入っているのが理想です。古い場合は [.NET ダウンロード](https://dotnet.microsoft.com/) から入れます。

プロジェクトを復元してビルドします。

```powershell
cd C:\Users\PC_User\Desktop\dev\sound
dotnet restore
dotnet build
```

成功すれば、学習用の実行環境は揃っています。

## アプリの起動パターン

| コマンド | 意味 |
|----------|------|
| `dotnet run -- --demo` | デモディスク。学習の定番 |
| `dotnet run -- --help` | 使い方 |
| `dotnet run -- --self-check` | ドメイン計算の自己診断 |
| `dotnet run -- --smoke` | 再生パイプラインの短い通し確認 |

`--` の左側は `dotnet` 用、右側は SOUND 用です。忘れやすいので覚えてください。

## プロジェクトファイル

`Sound.CdPlayer.fsproj` が設計図です。重要なところだけ抜き出します。

```xml
<OutputType>Exe</OutputType>
<TargetFramework>net10.0-windows</TargetFramework>
<UseWindowsForms>true</UseWindowsForms>
```

- `Exe` … 実行ファイル（コンソールアプリ）
- `net10.0-windows` … Windows 専用。CD とミラー窓が Win32 / WinForms に依存するため
- `UseWindowsForms` … `ShareWindow.fs` の別窓用

依存ライブラリは 2 つです。

```xml
<PackageReference Include="NAudio" Version="2.2.1" />
<PackageReference Include="Spectre.Console" Version="0.51.1" />
```

`<Compile Include="...">` の並びがコンパイル順です。`Domain.fs` が先頭、`Program.fs` が末尾です。新しい `.fs` を足すときは、使う側より上に置きます。

## F# Interactive（fsi）

レッスンの演習はスクリプト（`.fsx`）です。コンパイルしなくても、対話的に実行できます。

```powershell
dotnet fsi
```

プロンプト `>` が出たら、次を入力して Enter、続けて `;;` と Enter です。`;;` が「ここまで実行」の印です。

```fsharp
let greeting = "SOUND"
printfn "hello, %s" greeting
;;
```

終了は `#q;;` です。

ファイルごと実行する方が楽です。

```powershell
dotnet fsi study/exercises/01-values.fsx
```

実験用に `study/scratch.fsx` を作っても構いません。git には入りません。

## モジュールと名前空間

本番コードのほぼすべてが、次の形です。

```fsharp
namespace Sound

module TimeFmt =
    let mmss (t: TimeSpan) = ...
```

- `namespace Sound` … プロジェクト全体の箱
- `module TimeFmt` … その中の関数の集まり

`Program.fs` だけは `module Program` から始まり、`[<EntryPoint>]` の `main` があります。エントリポイントは 10 で詳しく見ます。

C# の `using` に当たるのが `open` です。

```fsharp
open System
open Spectre.Console
```

`open` すると、`System.Console` ではなく `Console` と書けます。

## エディタの補足

Cursor で `.fs` を開くと、型のヒントやエラーが出ます。赤線が出ても、まず `dotnet build` のメッセージを信じてください。

F# はインデントでブロックを表します。タブとスペースを混ぜるとエラーになります。このリポジトリはスペースです。
