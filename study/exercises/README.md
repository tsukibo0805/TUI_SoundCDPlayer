# 演習

レッスンを読んだあと、同じ番号の `.fsx` を開いて `TODO` を埋めます。

## 初めて解くときの進め方

一度に全部書く必要はありません。各ファイルを上から順に、次の手順で進めます。

1. `TODO 1-a` のような一番小さい小問を探す
2. 周囲に用意された関数・`match`・パイプの外枠を読む
3. その `failwith "TODO ..."` だけを式に置き換える
4. ファイルを保存して、下のコマンドを実行する
5. 今書いた項目が `OK` になったら、次の `TODO` へ進む

```powershell
dotnet fsi study/exercises/01-values.fsx
```

最初は、まだ解いていない次の `TODO` で実行が止まります。これは正常です。上から順に埋めてください。

- `OK`：その入力では期待どおりです
- `FAIL`：`expected` が期待値、`actual` が実際の値です
- `TODO` 例外：そこが次に書く場所です
- コンパイルエラー：表示された行番号の近くで、括弧・インデント・型を確認します

全部 `OK` になればクリアです。自動検査より下は変更しません。

## 補助線の使い方

演習には完成形の説明だけでなく、途中の値を作る小問とコードの外枠があります。まず外枠の「入力がどれで、最後に何を返すか」を読み、`a` から順に埋めます。まだ分からなければ対応レッスンの同じ構文を探し、それでも止まったときだけ `../answers/` の同じ番号を見ます。

各設問の `仕様:` には、F#を理解していてもコードだけからは決められないアプリ上の約束を書いています。たとえば「曲番号は1始まり」「CDは75フレームで1秒」「該当しないキーは無視する」などです。ここは推測せず、先に読んでから実装します。
