# 04. レコードとモジュール

レコードは「名前の付いたフィールドをまとめたデータ」です。モジュールは「関数の棚」です。SOUND のドメインは、この 2 つと DU の組み合わせです。

対応コード: `src/Domain.fs` の `Track`, `Disc`, `EqBand`, `EqPreset`

演習: `study/exercises/03-records.fsx`

## レコードを定義する

```fsharp
type Track = {
    Index: int
    Number: int
    Title: string
    Duration: TimeSpan
    Source: TrackSource
    Rip: RipInfo option
}
```

タプル `(int * string * TimeSpan)` より、名前がある分だけ読みやすいです。`Source` が DU、`Rip` が option です。型を組み合わせて、1 曲の意味を作っています。

作るときはフィールド名を書きます。

```fsharp
let track = {
    Index = 0
    Number = 1
    Title = "ホワイトノイズ"
    Duration = TimeSpan.FromSeconds 40.0
    Source = DemoTone Noise
    Rip = None
}
```

読むときはドットです。`track.Title`。

## コピーして一部だけ変える

レコードは原則として不変です。1 フィールドだけ変えた新しい値は、`with` で作ります。

```fsharp
let renamed = { track with Title = "ノイズ" }
```

`Player.StartRip` の中に、本番の例があります。

```fsharp
disc <-
    { disc with
        Tracks =
            disc.Tracks
            |> Array.map (fun t ->
                match t.Rip, Map.tryFind t.Number byNumber with
                | Some _, _ -> t
                | None, Some rip -> { t with Rip = Some rip }
                | None, None -> t)
    }
```

ディスク全体を破壊するのではなく、「Tracks だけ更新した新しい Disc」を作って入れ直しています。

## 可変フィールド

例外が `EqBand` です。

```fsharp
type EqBand = {
    Label: string
    Frequency: float32
    mutable GainDb: float32
}
```

スライダーを動かすたびにレコードを作り直すと、イコライザ本体が持っている参照とずれます。ここだけ `mutable` にして、同じオブジェクトのゲインを更新します。

```fsharp
band.GainDb <- EqPreset.clampGain (band.GainDb + delta)
```

「ドメインのスナップショットは不変レコード、今いじっているツマミだけ可変」という割り切りです。全部を可変にする必要はありません。

## モジュール

`module` は、関連する関数を名前の下に集めます。

```fsharp
module EqPreset =
    let minGain = -12.f
    let maxGain = 12.f
    let q = 1.41f

    let createBands () : EqBand array =
        [|
            { Label = "32"; Frequency = 32.f; GainDb = 0.f }
            // ...
            { Label = "16k"; Frequency = 16000.f; GainDb = 0.f }
        |]

    let clampGain (db: float32) =
        Math.Clamp(db, minGain, maxGain)
```

`EqPreset.createBands ()` のように呼び出します。`()` は「引数なし」です。毎回新しい配列を作ります。

同じファイルにある他のモジュールです。

| モジュール | 役割 |
|------------|------|
| `EqPreset` | 10 バンドの初期値とゲイン制限 |
| `TimeFmt` | 時間の表示とセクタ→時間 |
| `CdMath` | MSF と LBA の変換 |

どれも状態を持ちません。入力を受けて値を返すだけです。テストしやすい形なので、`Program.fs` の `--self-check` もここを叩いています。

## 配列リテラル

`[| ... |]` が配列です。`EqPreset.createBands` とデモディスクの定義で使います。

```fsharp
[| 1; 2; 3 |]          // int array
[ 1; 2; 3 ]            // int list（イミュータブルな連結リスト）
```

SOUND のトラック一覧は配列です。インデックスで「今の曲」を指すからです。list は演習で少し触れる程度で十分です。

レコードを 1 行で書くときは、フィールドを `;` で区切ります。複数行なら改行だけでよく、`;` は任意です。

## option フィールド

`Track.Rip` は `RipInfo option` です。

```fsharp
type RipInfo = {
    Drive: string
    StartLba: int
    Sectors: int
}
```

デモやフォルダ盤には抽出元がありません。`None` です。デジタル CD のトラックだけ `Some { ... }` です。

「無いかもしれない」を `null` にしないのが F# の基本です。次の次のレッスンで詳しく扱います。

## 型の組み立て方

`Disc` をもう一度見てください。

```fsharp
type Disc = {
    Title: string
    Artist: string
    Kind: DiscKind
    Drive: string option
    Tracks: Track array
}
```

- `Kind` は DU（何の盤か）
- `Drive` は option（ドライブレターがある盤だけ）
- `Tracks` はレコードの配列
- 各 `Track.Source` はまた DU

「大きなクラス 1 つ」ではなく、小さな型を組み合わせています。画面もプレイヤーも、この形を共有します。
